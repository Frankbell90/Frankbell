# Portfolio assets

Add original image files in this folder when ready.

Suggested files:
- `logo.png` — original Bello Graphics & Prints logo (transparent PNG preferred).
- `profile.jpg` — professional portrait.
- `project-01.jpg`, `project-02.jpg`, etc. — completed graphic design projects.
- `website-01.jpg`, `website-02.jpg`, etc. — screenshots of websites you have built.

Use clear, high-resolution images. Keep filenames simple and use lowercase letters and hyphens.

Do not add client-sensitive material unless you have permission to display it publicly.
